Where do I get a metadata ZIP?

🔌 Option 1 — SFDC Inspector Reloaded (Chrome extension)

Install SFDC Inspector Reloaded, open it while logged into your Salesforce org, then use its Metadata Retrieve tool to pick the components/types you want and download the result as a ZIP. This produces a classic Metadata API package (an unpackaged/ folder with .object, .profile, .flow files) — supported directly by this tool.

📦 Option 2 — Download a ZIP from a Git repo

If your metadata lives in an SFDX project on GitHub/GitLab, open the repo → Code → Download ZIP. That gives an SFDX source-format package (e.g. force-app/main/default/... with -meta.xml suffixed files) — also supported directly, no conversion needed.

Both classic Metadata API retrieve format and SFDX source format are supported — just drop whichever ZIP you have.
